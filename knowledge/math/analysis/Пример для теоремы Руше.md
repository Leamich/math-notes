Что можно сказать про уравнение $z+e^{ -z }=\lambda>1$.

Поймем, что оно имеет единств. решение в правой полуплоскости.

Будем рассматривать полуокружность с $R$ ($\to +\infty$).

Применим [[Теорема Руше]] для $f(z)=z-\lambda$ и $g(z)=e^{ -z }$. Проверим, что $\lvert f(z) \rvert>\lvert g(z) \rvert$ на мнимой оси и на полуокр.

* мнимая ось. $\lvert f(iy) \rvert=\lvert iy-\lambda \rvert=\sqrt{\lambda^{2}+y^{2}}\geqslant \lvert \lambda \rvert>1;\ \lvert g(iy) \rvert=\lvert e^{ -iy } \rvert\leqslant 1$
* полуокружность. $\lvert g(R e^{ it }) \rvert=\lvert e^{ -R \cos t- iR\sin t } \rvert=e^{ -R\cos t }\leqslant 1$; $\lvert f(R e^{ it }) \rvert\geqslant \lvert R e^{ it } \rvert-\lvert \lambda \rvert=R-\lambda$. Тогда для $R>\lambda +1$ нер-во верно.

Тогда у $f, g$ одинак. кол-во нулей в полукруге. Но у $f$ ровно один нуль $\implies f+g$ — тоже ровно один нуль.
