Подставим в [[Теорема о представлении мероморфной функции с последовательностью полюсов через ряд Лорана]] $f(z)=\frac{\ctg z}{z}$.

Особые точки: $\pi k$. При $k=0$ — полюс второго порядка. При $k\neq 0$ — полюс первого порядка.

* $k\neq 0$

$\mathop{\mathrm{res}}\limits_{z = \pi k}\,f=\mathop{\mathrm{res}}\limits_{z = \pi k}\, \frac{\left( \frac{\cos z}{z} \right)}{\sin z}= \frac{\frac{\cos z}{z}}{(\sin z)'}\bigg|_{z=\pi k}^{}= \frac{1}{z}\bigg|_{z=\pi k}^{}=\frac{1}{\pi k}$

$G_{k}(z) = \frac{\mathop{\mathrm{res}}\limits_{z = \pi k}\, f}{z-\pi k}=\frac{1}{\pi k(z-\pi k)}$

* $k=0$

$G_{0}(z)= \frac{a}{z}+\frac{b}{z^{2}}$, $a=0$, т.к. $f$ — четная.

$b=\lim\limits_{ z \to 0 }z^{2}f(z)=\lim\limits_{ z \to 0 } \frac{z}{\sin z}\cdot \cos z=1$

Итого, $G_{0}(z)=\frac{1}{z^{2}}$.

Из [[Лемма об ограниченности котангенса]] $\lvert f(z) \rvert\leqslant \frac{M}{\pi k}\to 0$ при $\lvert z \rvert=\pi k+\frac{\pi}{2}$

Тогда по [[Теорема о представлении мероморфной функции с последовательностью полюсов через ряд Лорана|th]] 
$$
\begin{gathered}
\frac{\ctg z}{z}= \lim\limits_{ k \to \infty } \left( G_{0}(z)+\sum\limits_{j=-k,\ j\neq 0}^{k} G_{j}(z) \right)=\lim\limits_{ k \to \infty }\left( \frac{1}{z^{2}}+\sum\limits_{j}^{}\left[ \frac{1}{\pi j(z-\pi j)}+ \frac{1}{-\pi j(z+\pi j)} \right] \right)=\\
= \frac{1}{z^{2}}+\sum\limits_{k=1}^{+\infty} \frac{2}{z^{2}-(\pi k)^{2}}
\end{gathered}
$$

Сходится для $z\neq \pi k$ (для фикс. $z$ слаг. убывают как обратный квадрат). Более того, сх-ся равномерно для огр. $z$ по [[Признак Вейерштрасса]]

Тогда $\ctg z=\frac{1}{z}+\sum\limits_{k=1}^{+\infty} \frac{2z}{z^{2}-\pi^{2}k^{2}}$.
