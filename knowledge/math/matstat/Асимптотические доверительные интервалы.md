Пусть $T$ — [[Требования к оценкам|Асимптотически нормальная оценка]] c $\sigma(\theta)$ непр.

Тогда $\sqrt{n} \frac{T_{n}-\theta}{\sigma(\theta)}\overset{d}{\to}\mathcal{N}(0, 1)$

$T_{n}\overset{\mathbb{P}}{\to}\theta$ (т.к. асимп. норм. $\implies$ [[Требования к оценкам|сост.]]) $\implies \sigma(T_{n})\overset{\mathbb{P}}{\to}\sigma(\theta)$ (несложно доказать через определение [[Непрерывность функции|непр.]] + [[Сходимость случайных величин по вероятности|сх-ти]])

$$
\sqrt{n} \frac{T_{n}-\theta}{\sigma(T_{n})} \overset{d}{\to} \mathcal{N}(0, 1)
$$
(по [[Лемма Слуцкого]])

Возьмем $Z:=\Phi ^{-1}\left( \frac{1+\gamma}{2} \right)$ из [[Доверительные интервалы для нормального распределения#ДИ с известной дисперсией|ДИ для нормального]], тогда $T_{n}\pm \frac{\sigma(T_{n})\cdot Z(\gamma)}{\sqrt{n}}$ — ДИ уровня $\gamma$.
## Пример

$\hat{\theta}$ — [[Оценка максимального правдоподобия|ОМП]] + [[Регулярные условия]] $\implies \sqrt{n}(\hat{\theta}-\theta)\overset{d}{\to} \mathcal{N}\left( 0, \frac{1}{I_{1}(\theta)} \right)$ (по [[Неравенство Рао-Крамера]]).
