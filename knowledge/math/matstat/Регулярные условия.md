1. [[Оценка максимального правдоподобия|Функция правдоподобия]] $L(\theta, x)$ положительна и дифф. по $\theta$.
2. score-функция $U(\theta, x)=\frac{ \partial  }{ \partial \theta } \log L(\theta, x)$ имеет конечную дисперсию (см. [[Информация Фишера]])
3. Дифф. по $\theta$ можно менять местами с интегрированием в мат. ожиданиях рассматриваемых статистик:
$$
\frac{ \partial  }{ \partial \theta } \int\limits T(x) L(\theta, x)\,d\nu(x) = \int\limits T(x) \frac{ \partial  }{ \partial \theta } L(\theta, x)\,d\nu(x)
$$
