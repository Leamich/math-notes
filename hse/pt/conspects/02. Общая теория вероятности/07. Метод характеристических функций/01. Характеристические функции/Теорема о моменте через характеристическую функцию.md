Если $\mathbb{E}\lvert \xi \rvert^{n}<+\infty$, то

$$
\varphi_{\xi}^{(k)}(t)=\mathbb{E}[(i\xi)^{k}e^{ it\xi }]\text{ при }k\leqslant n
$$

В частности, $\varphi_{\xi}^{(k)}(t)=i^{k}\cdot \mathbb{E}\xi^{k}$ при $k\leqslant n$

(см. [[Характеристическая функция случайной величины]])

## Следствие

$\mathbb{E}\xi=-i\varphi_{\xi}'(0)$ и $\mathbb{D}\xi=-\varphi''_{\xi}(0)+(\varphi'_{\xi}(0))^{2}$.

## Док-во

(ММИ по $k$).

**Переход**. $k\to k+1$

$$
\begin{gathered}
\varphi_{\xi}^{(k+1)}(t)=\lim\limits_{ h \to 0 } \frac{\varphi^{(k)}(t+h)-\varphi^{(k)}(t)}{h}\stackrel{\text{И.П.}}{=} \lim\limits_{ h \to 0 }  \frac{\mathbb{E}[(i\xi)^{k}e^{ i(t+h)\xi }]-\mathbb{E}[(i\xi)^{k}e^{ it\xi }]}{h}=\\
=\lim\limits_{ h \to 0 } \mathbb{E}\left[ (i\xi)^{k}e^{ it\xi }\cdot\frac{e^{ ih\xi }-1}{h} \right]\stackrel{?}{=}\mathbb{E}\left[ (i\xi)^{k} e^{ it\xi } \cdot \underbrace{ \lim\limits_{ h \to 0 } \frac{e^{ ih\xi }-1}{h} }_{ i\xi } \right]=\mathbb{E}[(i\xi)^{k+1}e^{ it\xi }]
\end{gathered}
$$

Осталось придумать суммир. мажоранту, чтобы поменять местами инт. и предел (см. [[Теорема Лебега о предельном переходе (о мажорируемой сх-ти)|th Лебега]]).
$$
\left\lvert  (i\xi)^{k}e^{ it\xi } \cdot \frac{e^{ ih\xi }-1}{h}  \right\rvert= \lvert \xi \rvert ^{k} \cdot \left\lvert  \frac{e^{ ih\xi }-1}{h}  \right\rvert 
$$

если $\lvert h\xi \rvert\geqslant 1$, то $\left\lvert  \frac{e^{ ih\xi }-1}{h}  \right\rvert\leqslant \frac{2}{h}\leqslant 2\lvert \xi \rvert$
если $\lvert h\xi \rvert<1$, то $\left\lvert  \frac{e^{ -ih\xi }-1}{h}  \right\rvert=\left\lvert  \frac{1+\mathcal{O}(ih\xi)-1}{h}  \right\rvert=\mathcal{O}(\xi)\leqslant C\lvert \xi \rvert$

Тогда общая оценка сверху $\leqslant C\lvert \xi \rvert^{k+1}$ — а он суммир. (т.к. $n\geqslant k+1$ момент конечен, тогда по [[Математическое ожидание|неравенству Ляпунова]] и $k+1$ момент конечен).
