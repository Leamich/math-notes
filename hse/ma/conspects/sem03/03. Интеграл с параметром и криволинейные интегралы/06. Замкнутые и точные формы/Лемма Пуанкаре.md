$\Omega$ — выпукл. [[Область]], коэф. [[Дифференциальная форма 1-го порядка]] из $C^{1}$

Тогда [[Замкнутая форма]] $\implies$ [[Точная форма]]

>[!note]- Выпуклость существенное условие
> 
> $\Omega=\mathbb{R}^{2}\setminus \{ 0 \},\ \omega=\frac{x\,dy-y\,dx}{x^{2}+y^{2}}$
> 
> Посчитаем инт. от $\omega$ по единич. кругу (см. [[Теорема о равносильностях для первообразной от дифф формы]], должен быть 0 для любой замкнутой кривой)
> $\gamma(t)=\begin{pmatrix}\cos t\\ \sin t\end{pmatrix}\quad \gamma:[0, 2\pi]\to \mathbb{R}^{2}$
> 
> $$
> \int\limits _{\gamma} \frac{x\,dy-y\,dx}{x^{2}+y^{2}}=\int\limits_{0}^{2\pi} \frac{\cos t\,d\sin t-\sin t\,d\cos t}{\underbrace{ \cos ^{2}t+\sin ^{2}t }_{ =1 }}=\int\limits_{0}^{2\pi} (\cos ^{2}t-\sin t(-\sin t))\,dt=\int\limits_{0}^{2\pi} dt=2\pi\neq 0
> $$

>[!question] Придумать локальн. первообр. для примера выше

## Следствие

1. если $\Omega$ — выпукл., а коэф. $\omega$ из $C^{1}$, то $\omega$ — точн. $\iff \omega$ [[Локально точная форма]] $\iff \omega$ замк. (см. [[Теорема о связи точности и замкнутости формы]])
2. Если коэф. формы из $C^{1}$, то $\omega$ — лок. точн. $\iff \omega$ — замк.

### Док-во 2

$\impliedby:$ Пуанкаре. Берем окр-ть т. —круг, выпукл. обл.

## Док-во

(только для $\mathbb{R}^{2}$)

Надо д-ть, что $\int\limits$ по $\forall$ прямоуг. из $\Omega$ равен $0$ (см. замечание [[Точная форма]])

$$
\omega=P\,dx+Q\,dy\quad \int\limits _{\partial D}\omega=\int\limits_{\partial D} P\,dx+Q\,dy\stackrel{\text{Грин}}{=}\int\limits_{D} \underbrace{ \left( \frac{ \partial Q }{ \partial x } -\frac{ \partial P }{ \partial y }  \right) }_{ =0\ (\text{из замк.}) }\,d\lambda_{2}=0
$$
(см. [[Формула Грина]])
