$\Omega$ — [[Область]] $\mathbb{R}^{2}$, граница кот. сост. из кон. числа замк. кусочн. гладк. [[Кривая]], [[Положительная ориентация границы области|ориентированных положительно]].

$P, Q: \mathrm{Cl}\,\Omega\to \mathbb{R}$ ([[Замыкание множества]]), т.ч. $P, Q,\frac{ \partial P }{ \partial y },\frac{ \partial Q }{ \partial x }$ непр. на $\mathrm{Cl}\,\Omega$

Тогда $\int\limits_{\partial \Omega}P \,dx+Qdy=\int\limits_{\Omega}\left( \frac{ \partial Q }{ \partial x }-\frac{ \partial P }{ \partial y } \right)\,d\lambda_{2}$ (см. [[Криволинейный интеграл II рода]]), где $\partial \Omega$ — граница области.

## Следствие

$$
\lambda_{2}\Omega=\int\limits_{\partial\Omega} x\,dy=-\int\limits_{\partial\Omega} y\,dx=\frac{1}{2}\int\limits_{\partial\Omega} x\,dy-y\,dx
$$

## Док-во

Надо д-ть, что $\int\limits_{\partial \Omega} P\,dx\stackrel{?}=-\int\limits_{\Omega} \frac{ \partial P }{ \partial y }\,d\lambda_{2}$ и $\int\limits_{\partial \Omega} Q\,dy=\int\limits_{\Omega} \frac{ \partial Q }{ \partial x }\,d\lambda_{2}$

**Шаг 1**. $\Omega$ — [[Элементарная область]]

$$
\int\limits_{\Omega} \frac{ \partial P }{ \partial y } \,d\lambda_{2}=\int\limits_{a}^{b} \underbrace{ \int\limits_{\varphi(x)}^{\psi(x)} \frac{ \partial P }{ \partial y } \,dy\,dx }_{ =P(x, y)\bigg|_{y=\varphi(x)}^{y=\psi(x)} }=\int\limits_{a}^{b}(P(x, \psi(x))-P(x, \varphi(x)))\,dx 
$$
Растащим область интегрирования (границу) на 4 кусочка

![[Pasted image 20251222231156.png]]

$$
\int\limits_{\partial \Omega}^{} P\,dx=\int\limits _{I}+\int\limits _{II}+\int\limits _{III}+\int\limits _{IV}
$$

$\int\limits_{II}P\,dx=\int\limits_{\varphi(b)}^{\psi(b)}P(\gamma(t))\cancelto{ 0 }{ \gamma'_{1}(t) }\,dt=0$
$\gamma:[\varphi(b), \psi(b)]\to \mathbb{R}^{2},\ \gamma(t)=\begin{pmatrix}b\\t\end{pmatrix}$
$\gamma'_{1}(t)=0,\ \gamma_{2}'(t)=1$

$\int\limits_{IV}=0$ (анал.)

$\int\limits_{I}P\,dx=\int\limits_{a}^{b}P(t, \varphi(t))\,dt$
$\gamma:[a, b]\to \mathbb{R}^{2}$
$\gamma(t)=\begin{pmatrix}t\\\varphi(t)\end{pmatrix}$

$\int\limits_{III}P\,dx=-\int\limits_{a}^{b}P(t, \varphi(t))\,dt$
$\gamma :[a, b]\to \mathbb{R}^{2}$
$\gamma(t)=\begin{pmatrix}t\\ \psi(t)\end{pmatrix}$

Тогда $\int\limits_{\partial \Omega}^{} P\,dx=\int\limits _{I}+\int\limits _{II}+\int\limits _{III}+\int\limits _{IV}=\int\limits_{a}^{b}(P(t, \varphi(t))-P(t, \psi(t)))\,dt$

Для $Q$ анал.

**Шаг 2**. Если формула верна для $\Omega_{1}, \Omega_{2}$, то она верна и для их объед. (встык имеется в виду)

$$
\begin{gathered}
&\int\limits_{\partial \Omega_{1}} P\,dx+Q\,dy=\int\limits_{\Omega_{1}} \left( \frac{ \partial Q }{ \partial x } -\frac{ \partial P }{ \partial y }  \right)\,d\lambda_{2}\\
+&\\
&\int\limits_{\partial \Omega_{2}} P\,dx+Q\,dy=\int\limits_{\Omega_{2}} \left( \frac{ \partial Q }{ \partial x } -\frac{ \partial P }{ \partial y }  \right)\,d\lambda_{2}
\end{gathered}
$$

Так как при обходе по смежной границе мы пойдём в разные стороны, то они взаимосократятся.

$\int\limits_{\partial\Omega} P\,dx+Q\,dy=\int\limits_{\Omega_{1}\cup \Omega_{2}} \left( \frac{ \partial Q }{ \partial x }-\frac{ \partial P }{ \partial y } \right)\,d\lambda_{2}=\int\limits_{\Omega} \dots$ (можем добавить границу, т.к. м-во нулевой меры).

**Шаг 3**. Если ф-ла верна для каких-то областей, то она верна и для конеч. объед. таких областей. Т.е. д-ли ф-лу для конеч. объед. элем. областей.
