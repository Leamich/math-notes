# Обвязка сайта

Здесь лежит [Quartz](https://quartz.jzhao.xyz) — генератор, который собирает
из конспектов сайт. Папка названа с точки, чтобы Obsidian не индексировал её
как часть хранилища.

Править тут нужно только `quartz.config.yaml`, да и то с оговоркой: блок
`customMacros` переписывается автоматически из `preamble.sty`, руками его
трогать бесполезно.

`content/` — не исходник, а результат. Он собирается из заметок в корне
репозитория скриптом `meta/scripts/publish/export.py` приватного хранилища.

Собрать вручную:

```
npm ci
npx quartz plugin install --from-config
npx quartz build
```

Лицензия Quartz — MIT, см. `LICENSE.txt`.

## Обновить Quartz

`npx quartz upgrade` здесь не сработает: он тянет изменения через git, а эта
папка — часть чужого репозитория, без истории Quartz. Обновление руками:
склонировать свежий Quartz, перенести в него `quartz.config.yaml` и `content/`,
затем положить обратно сюда.
