1. Определить выпукла ли (сильно выпукла / с липшицевым градиентом?) функция $f(x):=\sum\limits_{i=1}^{n} x_{i}\log x_{i}$ на $D:=\{ x_{i}>0\mid \forall i \}$.

	$$
	\begin{gathered}
	(\nabla f)_{i} = \ln x_{i}+1 \\
	\frac{ \partial f }{ \partial x_{i}\partial x_{j} } = \frac{ \partial  }{ \partial x_{j} } (\ln x_{i}+1) = \mathbb{1}[i=j] \cdot \frac{1}{x_{i}}
	\end{gathered}
	$$
	
	Тогда $\nabla^{2}f=\mathrm{diag}\left( \frac{1}{x_{1}},\dots, \frac{1}{x_{n}} \right)\implies$ все с.ч. $\frac{1}{x_{1}},\dots, \frac{1}{x_{n}}>0$ $\implies \nabla^{2}f\succ 0$ $\implies f$ — выпукл.
	
	*Про $\mu$-сильн. выпукл.*: $\nabla^{2}f \succeq \mu I$? Нет, т.к. $\inf\limits \lambda_{\min}(\nabla^{2}f)=0$
	
	*Про липшицевость*: $\lambda_{\max}\nabla^{2}f= +\infty\implies$ $f\centernot \in C^{1,1}_{L}$.

2. Определить выпукла ли (сильно выпукла / с липшицевым градиентом?) функция $f(x):=\sum\limits_{i=1}^{n} x_{i}\log x_{i}$ на $D:=\{  0<x_{i}<M\mid \forall i \}$.

	По сравнению с предыдущим есть $\mu$-сильн. выпуклость, т.к. есть $\inf\limits \lambda_{\min}\nabla^{2}f= \frac{1}{M}>0$ — наша $\mu$.

3. Найти наим. знач. ($C \neq 0, \sigma>0$): $f(x):=\frac{\sigma}{5}\lVert x \rVert_{2}^{5}-\langle c,x \rangle$.
	1. Найти стационарные точки
	2. Проверить выпуклость

	$$
	d(\lVert x \rVert _{2}^{5})=d(\langle x,x \rangle ^{5/2})= \frac{5}{\cancel{ 2 }}\cdot \langle x,x \rangle ^{3/2}\cdot \cancel{ 2 }\langle x,dx \rangle =5\lVert x \rVert _{2}^{3}\cdot \langle x,dx \rangle 
	$$
	$$
	df = \sigma \lVert x \rVert ^{3}_{2}\cdot \langle x, dx \rangle - \langle c, dx \rangle = \langle \underbrace{ \sigma \lVert x \rVert ^{3}_{2} \cdot x -c  }_{ \nabla f }, dx\rangle   
	$$
	Тогда $\nabla f=0$ $\iff$ $\sigma \lVert x \rVert^{3}_{2}\cdot x=c$. Заметим, что т.к. $\sigma>0$, то $x\upuparrows c$, осталось только найти коэффициент растяжения $k:  x=kc$ $\implies \sigma \lVert kc \rVert^{3}_{2}\cdot (kc)=c$ $\iff \sigma k^{4} \lVert c \rVert_{2}^{3}\cdot c=c$ $\implies k^{4}=\frac{1}{\sigma\lVert c \rVert_{2}^{3}}\implies k=\sqrt[4]{\frac{1}{\sigma \lVert c \rVert_{2}^{3}}}$.
	
	Найдем $d^{2}f$:
	$$
	\begin{gathered}
	d^{2}f=\sigma d(\lVert x \rVert _{2}^{3})\langle x, dx_{1} \rangle + \sigma \lVert x \rVert _{2}^{3}\langle dx_{2}, dx_{1} \rangle=\\
	=3\sigma \lVert x \rVert _{2} \cdot \underbrace{ \langle x, dx_{2} \rangle\cdot \langle x, dx_{1} \rangle }_{ (dx_{1})^{\top}x x^{\top}dx_{2} } + \sigma \lVert x \rVert _{2}^{3}\langle dx_{2}, dx_{1} \rangle=\\
	=3\sigma \lVert x \rVert _{2} \langle dx_{1}, x x^{\top}dx_{2} \rangle + \sigma \lVert x \rVert _{2}^{3}\langle dx_{2}, dx_{1} \rangle =\\
	=\langle dx_{1}, \sigma \lVert x \rVert _{2}(3  x x^{\top} + \lVert x \rVert _{2}^{2})dx_{2} \rangle 
	\end{gathered}
	$$
	
	Тогда надо проверить, что $\nabla^{2}f=\sigma \lVert x \rVert_{2}(3xx^{\top}+\lVert x \rVert_{2}^{2}I)\succ 0$ $\iff x x^{\top}\succ 0\iff \langle x x^{\top}h, h \rangle> 0 \iff$ $\langle x^{\top}h, x^{\top}h \rangle> 0$ — ну это есть.

## Коэрцитивность

**def**. $f:\mathbb{R}^{n}\to \mathbb{R}$ — коэрцитивна, если $f(x)\overset{\lvert x \rvert\to +\infty}{\to} +\infty$ (это обобщается как то что на границе области определения $D(f)$ функция уходит в бесконечность).

**Факт**. Если $f \in C(\mathbb{R}^{n})$ и коэрц., то $\exists$ наим. знач.

*Док-во*. $\forall x: \lVert x \rVert>R: f(x)>f(0)$ — рассмотрим такой $R$. Тогда $\overline{B}_{R}(0)$ — компакт $\implies \exists$ наим. знач. на $\overline{B}_{R}(0)$ — $x^{\star}$. Тогда $\forall x: \lVert x \rVert>R: f(x)>f(0)\geqslant f(x^{\star})$ $\implies x^{\star}$ — глобально наим. знач.

## Выпуклость множеств

4. Д-ть, что м-ва выпуклы: $A_{1}:=\{ \langle a,x \rangle\leqslant c \},\ a\in \mathbb{R}^{n},\ c \in \mathbb{R}$, $A_{2}:=\{ \lVert x \rVert\leqslant c \}$.

	Ну это несложно. Например, для $A_{2}: \lambda \in(0, 1);\ x_{1},x_{2}\in A_{2}$
	$$
	\lVert \lambda x_{1}+(1-\lambda)x_{2} \rVert \leqslant \lambda \lVert x_{1} \rVert +(1-\lambda)\lVert x_{2} \rVert \leqslant \lambda c+(1-\lambda)c=c
	$$

**def**. $c \in \mathbb{R}$. Тогда $f_{c}:=\{ x \in E: f(x)=f(c) \}$ — **линия уровня**.

**Утв.** $f$ — выпукл, то $\mathrm{Lev}f(c):=\{ x\mid f(x)\leqslant c \}$ — выпукл.
