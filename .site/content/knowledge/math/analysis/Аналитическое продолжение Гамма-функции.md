## Пример

$\Gamma(z):=\int\limits_{0}^{+\infty}e^{ -t }\cdot t^{z-1}dt$

Поймем, что при $\mathrm{Re}z>0$ инт. сх-ся.

$$
\lvert e^{ -t }\cdot t^{z-1} \rvert = e^{ -t }\lvert t^{z-1} \rvert =e^{ -t}\lvert e^{ (z-1)\ln t } \rvert= 
$$

$\lvert e^{ u+iv } \rvert = \lvert e^{ u }(\cos v + i \sin v) \rvert =e^{ u }$

$$
=e^{ -t} e^{ (\mathrm{Re}z-1) \ln t }=e^{ -t }\cdot t^{\mathrm{Re}z - 1}
$$

$\int\limits_{0}^{+\infty}e^{ -t }t^{\mathrm{Re}z-1}\,dt=\Gamma(\mathrm{Re}z)$ — сх-ся

Покажем, что $\Gamma \in H(\mathrm{Re}z>0)$. Тогда $\Gamma'(z)=\int\limits_{0}^{+\infty}e^{ -t }\ln t\cdot t^{z-1}\,dt$, если для $\Gamma'$ есть [[knowledge/math/analysis/Теорема о перестановке предела и интеграла с параметром|Локальное условие Лебега]].

Пусть $0<a<\mathrm{Re}z <b$. $\lvert e^{ -t }\ln t\cdot t^{z-1} \rvert\stackrel{0<t\leqslant 1}\leqslant e^{ -t }\lvert \ln t \rvert t^{a-1}$. 
$\lvert e^{ -t }\ln t\cdot t^{z-1} \rvert\stackrel{t>1}{\leqslant}e^{ -t }\ln t\cdot t^{b-1}$

**Свойства**. (формулы верны для вещ. $z$, слева и справа голом. ф-и $\implies$ ф-лы есть везде по [[knowledge/math/analysis/Теорема о единственности|Теорема о единственности]])
1. $\Gamma (z+1)=z\Gamma(z)$ при $\mathrm{Re}z>0$
2. $\Gamma(z)\Gamma(1-z)=\frac{\pi}{\sin \pi z}$ при $0<\mathrm{Re}z<1$

**Анал. продолж. $\Gamma$**
$\Gamma_{1}(z):=\frac{\Gamma(z+1)}{z}$ при $\mathrm{Re}z>-1$ и $z\neq 0$
при $\mathrm{Re}z>0: \Gamma_{1}(z)=\Gamma(z)$ — [[knowledge/math/analysis/Непосредственно аналитическое продолжение|Непосредственно аналитическое продолжение]]

$\Gamma_{2}(z):= \frac{\Gamma_{1}(z)}{z}=\frac{\Gamma(z+2)}{z(z+1)}$ при $\mathrm{Re}z>-2$ и $z\neq 0, -1$
при $\mathrm{Re}z>-1: \Gamma_{2}(z)=\Gamma_{1}(z)$

Так продолжим $\Gamma$ на м-ве $\mathbb{C}\setminus \{ 0, -1, -2,\dots \}$. (см. [[knowledge/math/analysis/Аналитическое продолжение по цепочке областей|Аналитическое продолжение по цепочке областей]]).
