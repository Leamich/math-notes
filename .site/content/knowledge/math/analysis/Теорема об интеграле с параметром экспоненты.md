$f\in C[a, +\infty)$ и $\int\limits_{a}^{+\infty}f\,dx$ сх-ся

Тогда $F(t):=\int\limits_{a}^{+\infty}e^{ -xt }f(x)\,dx$ непр. на $[0, +\infty)$
(см. [[knowledge/math/analysis/Введение в интегралы с параметром|Введение в интегралы с параметром]])
## Док-во

$F_{b}(t):=\int\limits_{a}^{b}e^{ -xt }f(x)\,dx$

Возьмем $\varepsilon>0$. Найдется $c: \forall c<b<y: \left\lvert  \int\limits_{b}^{y}f\,dx\right\rvert<\varepsilon$ (по [[knowledge/math/analysis/Критерий Коши для сходимости несобственного интеграла|Критерий Коши для сходимости несобственного интеграла]])

Пусть $\int\limits_{b}^{y}f\,dx=:g(y)\text{ (первообр. для }f)$. 

$$
\begin{gathered}
\int\limits_{b}^{+\infty} e^{ -xt }f(x)\,dx\stackrel{\text{инт. по частям}}{=}\underbrace{ e^{ -xt }g(x)\bigg|_{x=b}^{x=+\infty} }_{ -g(b)e^{ -bt } \stackrel{\text{по мод.}}{<}\varepsilon}+ \int\limits_{b}^{+\infty} \underbrace{te^{ -tx }g(x)\,dx }_{ \lvert \dots \rvert <\varepsilon te^{ -xt } }
\end{gathered}
$$
Тогда
$$
\left\lvert  \int\limits_{b}^{+\infty} e^{ -xt }f(x)\,dx  \right\rvert\leqslant\varepsilon+\varepsilon \int\limits_{b}^{+\infty} te^{ -xt }\,dx=\varepsilon+\varepsilon(-e^{ -xt })\bigg|_{x=b}^{x=+\infty}=\varepsilon+\varepsilon e^{ -bt }\leqslant 2\varepsilon
$$

$$
\begin{gathered}
\lvert F(t)-F(t_{0}) \rvert =\left\lvert  F_{b}(t)- F_{b}(t_{0})+\left( \int\limits_{b}^{+\infty} e^{ -xt }f(x)\,dx-\int\limits_{b}^{+\infty} e^{ -xt_{0} }f(x)\,dx \right) \right\rvert \leqslant \\
\leqslant\lvert F_{b}(t)-F_{b}(t_{0}) \rvert +\underbrace{ \left\lvert  \int\limits_{b}^{+\infty} (\dots) \right\rvert +\left\lvert \int\limits_{b}^{+\infty} (\dots)  \right\rvert }_{ \leqslant 4\varepsilon }
\end{gathered}
$$
