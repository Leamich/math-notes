# Конспекты по математике

Конспекты, которые я вёл в Obsidian на первых курсах бакалавриата: матанализ,
алгебра, теория вероятностей, теория меры, дискретная математика, начала
методов оптимизации. Около 1400 заметок.

Читать онлайн: **https://leamich.github.io/math-notes/**

## Как открыть у себя

```
git clone https://github.com/Leamich/math-notes-vault.git
```

Дальше «Открыть папку как хранилище» в Obsidian и указать на клон. Всё уже
настроено: структура тем, оглавления, макросы для формул.

При первом открытии Obsidian предложит установить три плагина — они нужны,
чтобы хранилище работало целиком:

| Плагин | Зачем |
| --- | --- |
| **Breadcrumbs** | дерево тем по полю `up` и хлебные крошки над заметкой |
| **Obsidian Latex** | подхватывает `preamble.sty` с макросами `\tg`, `\ctg`, `\esssup` |
| **Latex Suite** | быстрый набор формул |

Оглавления тем собираются базой `meta/bases/Дети.base` — это ядро Obsidian,
ставить ничего не надо. Нужна версия 1.9 или новее.

## Как устроено

Навигацию несёт одно поле `up` во фронтматтере: оно указывает на ближайшего
родителя. Отсюда само вырастает и содержание темы, и программа курса —
это прямые дети соответствующей заметки.

```
Мат. анализ                        type: course
└── Непрерывность                  type: index,   up: [[Мат. анализ]]
    ├── Равномерная непрерывность   type: concept, up: [[Непрерывность]]
    └── Теорема Больцано-Коши       type: concept, up: [[Непрерывность]]
```

Заметки-хабы курсов (`courses/`) здесь — короткие заглушки: в исходном
хранилище на их месте лежат расписания, домашние задания и ссылки на записи
лекций, которым в открытом доступе не место.
