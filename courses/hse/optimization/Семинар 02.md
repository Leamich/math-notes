1. Найти $\nabla f, \nabla^{2} f$. $f(x):=\lVert x \rVert_{2}^{3}$
	$$
	\begin{gathered}
	d\langle x, x \rangle ^{3/2}=\frac{3}{2} \lVert x \rVert _{2} \cdot d\langle x, x \rangle=\frac{3}{\cancel{ 2 }} \lVert x \rVert _{2}\cdot \cancel{ 2 } \langle dx, x \rangle \implies \nabla f = 3 \lVert x \rVert _{2}^{} \cdot x 
	\end{gathered}
	$$
	$$
	\begin{gathered}
	d \langle 3 \lVert x \rVert x, dx_{1} \rangle = \langle 3 d(\lVert x \rVert x), dx_{1} \rangle = 3\left\langle  \frac{\langle x, dx_{2} \rangle}{\lVert x \rVert } \cdot x + \lVert x \rVert \cdot dx_{2}  ,\ dx_{1} \right\rangle=
	\end{gathered}
	$$
	
	Чтобы найти $\nabla^{2}f$ хотим привести $d^{2}f=\langle \nabla^{2}f(x)\,dx_{2}, dx_{1} \rangle$, то есть хотим в матрицу привести $\frac{\langle x, dx_{2} \rangle}{\lVert x \rVert}\cdot x$ (ну потому что второе слагаемое можно просто $\lVert x \rVert I\cdot dx_{2}$). Тогда заметим, что $\langle x, dx_{2} \rangle x = x\langle x, dx_{2} \rangle=xx^{\top}dx_{2}$, как раз получили нужный вид.
	$$
	=3\langle \left( \frac{xx^{\top}}{\lVert x \rVert } + I\lVert x \rVert  \right)dx_{2}, dx_{1} \rangle \implies \nabla^{2} f = \frac{x x^{\top}}{\lVert x \rVert }+I\lVert x \rVert 
	$$

2. $f:=\det X,\ X \in \mathbb{R}^{n\times n},\ \det X\neq 0$. Найти $\nabla f$. 
	Найдем $\frac{ \partial f }{ \partial x_{ij} }$. У нас [[Явная формула определителя|есть]] явная формула детерминанта через перестановки, но её немного долго считать. Рассмотрим тогда вспомним [[Разложение по столбцам-строкам|формулу разложения по строке]]
	$$
	\frac{ \partial f }{ \partial x_{ij} } = \frac{ \partial  }{ \partial x_{ij} } \left( \sum\limits_{k=1}^{n} (-1)^{i+k} x_{ik} A_{ik} \right)
	$$
	Тогда $(f')_{ij}=(-1)^{i+j}A_{ij}$, что практически [[Теорема о явной формуле для обратной матрицы|явная формула обратной матрицы]] $\implies \nabla f=X^{-1} \cdot \det X$.

3. Найти $d(X^{-1})$.
	Заметим, что $X^{-1}X = I$. Возьмем дифференциал:
	
	$$
	\begin{aligned}
	d(X^{-1})X + X^{-1}d(X)&=\cancelto{ 0 }{ d(I) }\\
	d(X^{-1})X +X^{-1}H&=0\\
	d(X^{-1})X&=-X^{-1}H\\
	d(X^{-1})&=-X^{-1}HX^{-1}
	\end{aligned}
	$$
	, где $H=dX$ (то есть дифференциал).

***

Заведем скалярное произведение для $A, B \in \mathbb{R}^{m\times n}$: $\langle A, B \rangle:=\sum\limits_{}^{}A_{ij}B_{ij}=\mathrm{tr}\,(A^{\top}B)$, оно согласуется с [[Матричные нормы|фробениусовой нормой]] $\lVert A \rVert_{F}= \langle A, A \rangle=\mathrm{tr}\,(A^{\top}A)$.

1. Найти $\nabla f$ для $f:=\mathrm{tr}\,(AX^{-1}B)=\langle I, AX^{-1} B\rangle$
	*Способ через скалярное произв.:*
	$$
	\begin{gathered}
	d\langle I, AX^{-1}B \rangle =\langle I, d(AX^{-1}B) \rangle =\langle I, Ad(X^{-1})B \rangle=\langle I, AX^{-1}HX^{-1}B \rangle=\\
	=\langle \underbrace{ -X^{-\top}A^{\top}B^{\top}X^{-\top} }_{ \nabla f }, H\rangle   
	\end{gathered}
	$$
	
	*Альтернативный способ:* заметим, что если $A=\mathrm{const}$, то мы можем , то есть дифференциал перестановочен с лин. отобр.
	
	$$
	d(\mathrm{tr}\,(AX^{-1}B))=\mathrm{tr}\,(Ad(X^{-1})B)=\mathrm{tr}\,(-AX^{-1}HX^{-1}B)
	$$
	
	Хотим $d(f)=\mathrm{tr}\,((\nabla f)^{\top}H)$ ($=\langle \nabla f, H \rangle$).
	
	*Замечание* (**Цикличность следа**). $\mathrm{tr}\,(ABC)=\mathrm{tr}\,(CAB)$
	
	Тогда, пользуясь цикличностью следа, имеем $\mathrm{tr}\,(-AX^{-1}HX^{-1}B)=\mathrm{tr}\,(-X^{-1}BAX^{-1}H)$.

2. Найти $\nabla f,\ f:=a^{\top}XAXa$, $A\in \mathbb{R}^{n\times n},\ a \in \mathbb{R}^{n}$.

$$
d(\mathrm{tr}\,(a^{\top}XAXa))= \mathrm{tr}\,(a^{\top}HAXa+a^{\top}XAHa)=\mathrm{tr}\,(AXaa^{\top}H+aa^{\top}XAH)
